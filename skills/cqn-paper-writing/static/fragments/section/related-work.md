# Related Work

## Structure
- Organise by topic or approach, not by paper
- Each paragraph covers one category of related work
- End each paragraph with the limitation that your work addresses

## Rules
- Cite the paper you actually read; not secondary sources
- Do not cite papers just to fill space — each citation should serve
  an argument
- Distinguish: method papers, application papers, review papers

## Avoid
- Laundry-list paragraphs: "Paper A did X. Paper B did Y. Paper C did Z."
- Instead: "Several approaches use transformer architectures for
  fault diagnosis [A, B, C]. However, none address the specific
  challenge of real-time inference on resource-constrained FPGAs [D]."
