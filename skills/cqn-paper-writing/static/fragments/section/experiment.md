# Experiment Section

## Structure
1. **Experimental platform** — hardware, firmware, instruments
2. **Measurement setup** — wiring, probe position, ground reference
3. **Test conditions** — voltage, current, temperature, load range
4. **Procedure** — step-by-step test sequence
5. **Parameters** — table of key parameters: sampling rate, bandwidth,
   calibration, units

## Required
- Sampling rate must be stated for every measurement
- Units must be on every quantity
- Calibration method must be described
- Any anti-aliasing filtering must be declared

## Rules
- A reader should be able to reproduce the experiment from this
  section alone
- If a parameter is device-specific, cite the datasheet
- Include a photo or diagram of the setup when feasible
