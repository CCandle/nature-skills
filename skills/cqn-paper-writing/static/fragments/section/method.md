# Method

## Structure
1. **System overview** — block diagram or architecture description
2. **Design rationale** — why this approach was chosen
3. **Key modules** — describe each novel or critical component
4. **Implementation details** — parameters, algorithms, equations

## Engineering-specific
- For hardware: schematic description, component values, part numbers
- For firmware: state machine, interrupt design, critical sections
- For FPGA: clock domains, IP cores, resource utilisation
- For AI: model architecture, training data, loss, hyperparameters

## Rules
- Include enough detail for a competent engineer in the field to
  reproduce the work
- If a detail is proprietary or protected, say so explicitly
- Use equations for algorithmic steps; text for design rationale
