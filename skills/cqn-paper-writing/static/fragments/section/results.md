# Results

## Structure
- Present results in logical order matching the Method section
- Each result subsection: claim → evidence (figure/table) → interpretation
- End with a summary of key findings

## Rules
- Do not present the same data in both a figure and a table
- Every figure/table must be referenced in the text
- Interpretation must stay within what the data supports
- Negative results and failures are valid results — include them
- Error bars, confidence intervals, or variability measures required
