# Claim-Source Mapping

## Mapping format

Each citation should map to a specific claim with:

| Field | Description |
|---|---|
| Claim text | The specific statement needing support |
| Citation | Full reference |
| Support type | Direct method / analogous approach / theoretical background / application precedent |
| Confidence | High / Medium / Low |
| Rationale | Why this citation supports this claim |

## Example

| Claim | Citation | Support type | Confidence | Rationale |
|---|---|---|---|---|
| ADC ENOB is limited by Vref noise in SAR converters | [1] J. Smith, "Vref noise analysis..." IEEE TIM, 2024 | Direct | High | Same topology, similar conditions |
| External reference improves low-frequency noise | [2] TI Application Note SLAA510 | Application precedent | Medium | Different ADC but same principle |
