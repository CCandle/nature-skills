# Data Availability Workflow

## Step 1: Inventory data
Ask the user to list all data and code generated in the study.
Categorise by type.

## Step 2: Determine access for each category
| Category | Access options |
|---|---|
| Raw data | Repository / upon request / cannot share |
| Processed data | Repository / upon request |
| Scripts | GitHub / repository / upon request |
| Firmware | Repository / upon request |
| Bitstream | Repository / upon request |
| Config files | Repository / included in supplement |

## Step 3: Draft statement
Combine into a coherent data availability statement per the output
structure.

## Step 4: FAIR check
Run through the FAIR checklist. Mark what is met and what is not.
