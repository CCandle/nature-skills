# Polishing Workflow

## Step 1: Review the draft
Read the complete draft. Identify sections with clarity issues,
awkward phrasing, or flow problems.

## Step 2: Polish sentence by sentence
- Improve clarity, conciseness, and flow
- Do not change meaning
- Do not add or remove evidence

## Step 3: Check claim language
- "Demonstrates" → only if directly supported by data [CF]
- "Suggests" or "Indicates" → for [RH] claims
- "May" / "Could" → for [UG] claims

## Step 4: Generate change log
List every modification with:
- Location (section, paragraph)
- Original text
- Revised text
- Reason

## Step 5: Final check
- Numbers unchanged
- Evidence tags unchanged
- Limitations unchanged
- Engineering accuracy preserved
