# CQN High-Impact Polishing — Adapter

Low-frequency skill. Polishes a completed draft for high-impact journal
language and flow. Does not add content, does not change evidence.

## Trigger condition

Only invoke when the user has a complete draft and names a target
high-impact journal, or explicitly asks for high-impact polishing.

## Rules

1. Do not change technical meaning
2. Do not add claims, evidence, or data
3. Do not remove or weaken limitation statements
4. Do not change [CF]/[RH]/[UG] tags
5. Do not inflate language — "demonstrate" if you have evidence,
   "suggest" if you do not
6. Output a change log showing every modification

## What can be changed

- Sentence structure for clarity
- Word choice for precision
- Paragraph organisation for flow
- Journal-specific formatting (heading style, citation format)
- Figure caption depth

## What cannot be changed

- Numerical values
- Experimental parameters
- Evidence tags
- Limitation statements
- Any claim without supporting evidence in the paper
