# Method Extraction

## What to extract from the method section

- System architecture diagram description
- Key algorithmic steps (numbered)
- Novel components vs standard building blocks
- Design rationale (why this choice over alternatives)
- Implementation language, framework, libraries

## Engineering-specific

- For FPGA papers: clock frequencies, resource utilisation, IP cores
- For power electronics: topology, switching frequency, modulation scheme
- For control papers: controller type, tuning method, stability analysis
- For AI papers: model architecture, training data, loss function
