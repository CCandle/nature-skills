# Experiment Extraction

## What to extract from the experimental section

- Hardware platform: board, FPGA, instrument, probe
- Test conditions: voltage, current, temperature, load
- Measurement setup: sampling rate, bandwidth, coupling, trigger
- Calibration: method, reference, range
- Software: OS, driver version, toolchain
- Data: dataset name, size, split, preprocessing

## Table format

| Parameter | Value in paper | Status |
|---|---|---|
| Board | Zynq KR260 | Provided |

| Vref | 3.3 V | Provided |
