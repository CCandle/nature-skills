# Output Spec

## Reading note structure

Produce a document with these sections in order:

1. One-sentence Summary
2. Research Problem
3. Main Claim
4. Method / System Architecture
5. Key Equations / Algorithms
6. Experimental Setup
7. Dataset / Conditions / Parameters
8. Results and Metrics
9. Reproducibility Checklist
10. Missing Reproducibility Information
11. What is useful for my research
12. What is questionable / underspecified
13. Possible follow-up experiments
14. Citation / Source Map

## Format

Markdown with clear section headings. Use tables for parameters
where possible.
