# Reproducibility Checklist

Check each item against the paper. Mark: Provided, Partial, Missing.

## Hardware
- [ ] Board / platform model and revision
- [ ] FPGA or processor model
- [ ] Instrument model and settings
- [ ] Probe type and position

## Firmware / Software
- [ ] Firmware version or commit hash
- [ ] Software version
- [ ] Toolchain version

## Parameters
- [ ] Sampling rate
- [ ] Signal bandwidth
- [ ] Calibration method
- [ ] Measurement units

## Dataset (ML papers)
- [ ] Dataset name and source
- [ ] Dataset size and split
- [ ] Preprocessing steps
- [ ] Data format

## Method
- [ ] Algorithm pseudocode or reference
- [ ] Hyperparameters
- [ ] Training / optimisation details

## Results
- [ ] Metric definitions
- [ ] Confidence intervals or error bars
- [ ] Ablation studies
- [ ] Comparison to baselines
