# Source Access Policy

## If source is directly available
- Read the source.
- Extract only what is present.
- Cite / source-map the extracted information.

## If source is DOI/arXiv/URL but retrieval tool is available
- Retrieve the source first.
- Do not rely on title/abstract snippets only unless user explicitly asks
  for abstract-only reading.

## If source cannot be retrieved
- State that the full source was not accessible.
- Work only from user-provided text or metadata.
- Mark missing sections as `Not accessible`.
- Do not fabricate methods, datasets, parameters, figures, or results.

## If only pasted text is provided
- Treat it as partial-source mode.
- Do not infer full-paper claims.
- See `static/fragments/source_type/text.md` for detailed rules.
