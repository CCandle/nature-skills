# Paper Reading Workflow

## Step 1: Source identification

Record the paper's title, authors, venue, DOI, and source type.

## Step 2: One-sentence summary

Write a single sentence that captures the paper's core contribution.

## Step 3: Extract research problem and claim

- What problem does the paper address?
- What is the main claim?
- Is the claim clearly stated?

## Step 4: Extract method

- System architecture or algorithm overview
- Key equations or design decisions
- Implementation details provided

## Step 5: Extract experimental setup

- Hardware platform (board, FPGA, instrument)
- Firmware / software versions (if given)
- Sampling parameters, calibration, conditions
- Dataset (if ML paper): size, source, split, preprocessing
- Baseline methods and comparison conditions
- Ablation studies performed

## Step 6: Extract results and metrics

- Key quantitative results
- How metrics are defined
- What comparisons are shown

## Step 7: Run reproducibility checklist

Check each item in references/reproducibility-checklist.md.
Mark what is provided and what is missing.

## Step 8: Assess research usefulness

- What can be used directly in my project?
- What needs adaptation?
- What is questionable or underspecified?
- What follow-up experiments does this suggest?
