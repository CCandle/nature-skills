# PDF Source

Selectable-text PDF provided as a file or upload.

## Extraction approach
- Read the PDF text directly. Identify sections: abstract, intro, method,
  experiments, results, conclusion.
- If the PDF has embedded figures, describe what they contain.
- If the PDF is scanned (image-only), note the limitation.

## Key sections to locate
- Hardware / experimental platform description
- Parameters table
- Baseline and comparison methods
- Dataset description (if ML paper)
