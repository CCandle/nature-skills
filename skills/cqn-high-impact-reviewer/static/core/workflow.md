# Reviewer Workflow

## Step 1: Read the manuscript
Identify the main claim, the evidence provided, and the limitations.

## Step 2: Map claims to evidence
| Claim in manuscript | Evidence provided | Tag in manuscript | Assessment |
|---|---|---|---|

## Step 3: Generate 3 reviewer reports
Each with a different emphasis (technical, novelty, presentation).
Use the same shared fact base.

## Step 4: Cross-review synthesis
Identify consensus across reviewers and diverging opinions.

## Step 5: Must-fix vs optional
Classify each issue as:
- Must-fix before submission (technical error, missing evidence)
- Should fix (clarity, completeness)
- Optional improvement (presentation, referencing)
