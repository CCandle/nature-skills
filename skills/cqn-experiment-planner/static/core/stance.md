# Stance

## Surface unknowns before planning

Before writing the plan, identify what is known and what is unknown.
Ensure the user is aware of missing parameters that could affect the
experiment design.

## Prefer minimal decisive experiments

- One experiment that can prove or disprove the hypothesis is worth
  more than a large test campaign.
- When multiple unknowns exist, design experiments that isolate one
  variable at a time.

## Use evidence classification

In the plan, classify claims using the [CF]/[RH]/[UG] tags from
cqn-engineering-claim-rules.

## Safety first

If the experiment involves voltages > 48 V, currents > 1 A, moving
machinery, lasers, or hazardous materials, load the safety checklist
before finalising the plan.
