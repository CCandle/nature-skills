# cqn-data-analysis

Analyse waveform, FFT, THD, ENOB, and engineering metrics from measurement data.

## Usage

Provide your data and analysis needs:

> Here's a CSV of ADC readings at 1 MS/s. The ADC is 12-bit with Vref=3.3V.
> Calculate the noise floor and ENOB.

Output: analysis report with all parameters declared, plus optionally a
Python analysis script.

## Key rules

- Every analysis parameter is declared in the report, not hidden in code
- Python scripts are optional, generated on request
- No example data — if you have no data, the skill asks for it
