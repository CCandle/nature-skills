# Response Workflow

## Step 1: Parse reviewer comments
Number every comment. Group by reviewer.

## Step 2: Classify each comment
| Type | Response strategy |
|---|---|
| Requested experiment | Explain feasibility, state planned/not |
| Clarity issue | Revise manuscript, quote before/after |
| Missing evidence | Add if available, explain if not |
| Technical question | Answer with evidence [CF]/[RH] |
| Disagreement | Explain reasoning, offer alternative |

## Step 3: Draft response per comment
Following the output structure.

## Step 4: Mark all changes
Every manuscript change must include the location (section, paragraph).

## Step 5: QA check
- Every comment addressed?
- Evidence claims tagged?
- Missing experiments marked?
- Professional tone throughout?
