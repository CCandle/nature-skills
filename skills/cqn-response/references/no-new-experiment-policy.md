# No New Experiment Policy

Rules for handling reviewer requests for new experiments.

## When a new experiment is requested

1. Assess feasibility: available equipment, time, budget
2. If feasible and planned, respond:
   "This experiment is planned and will be included in the revision."
   Mark as `requires new experiment`
3. If not feasible, explain why and propose an alternative:
   - "The requested temperature chamber is not available. As an alternative,
     we performed a sensitivity analysis using..."
4. Do NOT:
   - Fabricate experiment results
   - Claim an experiment was done when it was not
   - Ignore the comment

## If the experiment was already done but not in the manuscript
- Add the results to the manuscript
- Reference the addition in the response
- Mark as `resolved`
