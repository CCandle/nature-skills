# Manuscript Change Log

Track every change made in response to reviewer comments.

## Change log format

| # | Comment ref | Location | Change | Evidence added |
|---|---|---|---|---|
| 1 | R1.3 | §III.B, para 2 | Added Vref noise analysis | Fig. 5, Table 2 |
| 2 | R2.1 | §IV.A | Clarified settling time definition | — |

## Rules

- Every change must be traceable to a specific reviewer comment
- If no change was made, the entry should read:
  "No change — [reason]"
- Changes should be grouped by reviewer for the response letter
- The change log should be included in the response cover letter
