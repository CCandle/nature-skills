# Response-Evidence Map

Every reviewer response must map to a clear evidence track.

## Mapping table

| Comment | Response | Manuscript change | Evidence source | Status |
|---|---|---|---|---|
| (Reviewer text) | (Your response) | (Section, paragraph) | (Data file, reference) | resolved / partial / requires new experiment |

## Status definitions

| Status | Meaning |
|---|---|
| resolved | Comment addressed, manuscript updated, evidence provided |
| partially resolved | Addressed in text but evidence not fully available |
| requires new experiment | Cannot be resolved without additional data — explain and propose plan |

## Rules

- If a comment is resolved, the evidence source must be cited
- If partially resolved, state what is missing
- If a new experiment is needed but not done, say so — do not pretend
- If no manuscript change was made, justify why
