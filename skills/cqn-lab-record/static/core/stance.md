# Stance

## Structure over free text

Even when the input is a fragment or a verbal note, always produce
a structured record. Unstructured records cannot be traced.

## Tag evidence rigorously

Do not soften the classification. If there is no file or screenshot
to back a claim, it is at most `[RH]`.

## Preserve uncertainty

If the root cause is not confirmed, say so. A record that says
"Probably X, but Y is still possible" is more useful than one that
confidently states a wrong conclusion.
