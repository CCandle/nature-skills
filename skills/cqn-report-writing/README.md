# cqn-report-writing

Turn experiment records, analysis results, and project notes into structured
engineering research reports. Designed for group meetings, stage reports,
proposals, and project summaries.

## Usage

Provide your material and report type:

> Write a group meeting report based on this lab record and data analysis.
> I've been testing the ADC ENOB this week. Here are the results...

Output: structured report with evidence-classified claims, unknowns listed,
and clear next steps.

## Key rules

- Every claim tagged `[CF]` / `[RH]` / `[UG]`
- Missing evidence marked explicitly
- Direct, defensible style — not promotional
- For your supervisor or group meeting, not for journal submission
