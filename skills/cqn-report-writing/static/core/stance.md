# Stance

## Direct and defensible

State the results and their limitations in the same paragraph.
A report that only claims successes without mentioning limitations
will lose credibility when the limitations are inevitably discovered.

## Evidence classification

Every factual statement must be tagged `[CF]`, `[RH]`, or `[UG]` per
cqn-engineering-claim-rules. This is not optional.

## Missing evidence is not a problem — hiding it is

If a measurement was not taken, write "Not yet measured" or
"Missing evidence". Do not write around it with vague language.

## Audience awareness

Your supervisor and group members have limited time.
State the key finding, the key evidence, and the key open question
in the first paragraph of each section.
