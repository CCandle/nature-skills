# Stage Report

End-of-phase or milestone summary for project review.

## Purpose

Demonstrate progress against the project plan, document what has been
achieved, and update the plan for the next phase. Usually evaluated by
a supervisor, committee, or funding body.

## Structure

| Section | Purpose |
|---|---|
| Background | Problem statement and project context |
| Objectives | Original objectives for this phase |
| Completed work | What was done, with evidence |
| Key results | Metrics, waveforms, analysis summaries |
| Deviations | What changed vs original plan |
| Failure cases | What didn't work and lessons learned |
| Equipment / resource status | Working state of experimental platform |
| Next phase plan | Objectives and timeline for next phase |
| Risks | Updated risk register |

## Emphasis

- Clear linkage between objectives and completed work
- Deviations from plan should be explained, not hidden
- Each result should be traceable to an experiment record or data file
- Next phase plan must be concrete, not aspirational

## Tone

- Professional but direct
- Claim-evidence alignment is essential
- No exaggeration of results
