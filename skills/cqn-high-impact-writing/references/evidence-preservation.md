# Evidence Preservation Rules

When upgrading to high-impact style, evidence must be preserved, not diluted.

## What must NOT change
- Numerical values and experimental parameters
- Evidence classification tags [CF]/[RH]/[UG]
- Limitation statements
- Missing evidence markers
- Engineering accuracy of parameter descriptions

## What can change
- Sentence structure for clarity
- Section organisation for narrative flow
- Level of detail for introduction context
- Figure presentation (panel arrangement, colour, export format)

## Check before delivery
- [ ] All numbers unchanged from source material
- [ ] All [CF]/[RH]/[UG] tags present in the draft
- [ ] Limitations section not removed
- [ ] No new claims added without evidence
