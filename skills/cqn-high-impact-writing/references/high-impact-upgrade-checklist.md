# High-Impact Upgrade Checklist

Before upgrading an engineering draft for a high-impact journal, verify:

## Evidence readiness
- [ ] All `[CF]` claims have traceable evidence
- [ ] All `[RH]` claims are labelled as hypotheses
- [ ] No `[UG]` claims are presented as findings
- [ ] Missing experiments are explicitly marked

## Audience adaptation
- [ ] Introduction is accessible to a nonspecialist
- [ ] Key results are summarised in plain language
- [ ] Significance for a broad audience is stated
- [ ] Engineering details are kept in Methods or Supplementary

## Figure readiness
- [ ] Figures follow high-impact-paper mode (figure contract, panel logic)
- [ ] All axes labelled with quantity and unit
- [ ] Statistical information declared (n, test, error bars)
