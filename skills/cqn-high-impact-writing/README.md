# cqn-high-impact-writing

High-impact journal paper adapter. Upgrades engineering drafts for
Nature Communications / high-impact journals while preserving evidence
discipline.

## Usage

Provide your engineering draft and target journal:

> Take this cqn-paper-writing draft and adapt it for Nature Communications.

## Key rules

- Evidence tags [CF]/[RH]/[UG] are retained
- No fabricated data
- Broad-audience framing without losing engineering accuracy
