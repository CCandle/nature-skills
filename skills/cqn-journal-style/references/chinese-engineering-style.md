# Chinese Engineering Thesis Style

## Structure

- Chinese abstract first (300-500 words)
- English abstract second (200-300 words)
- Chapters numbered: 1, 2, 3
- Sections: 1.1, 1.2, 1.2.1
- References in order of appearance or author-year
- Acknowledgements before references

## Figure and table

| Element | Convention |
|---|---|
| Figure label | "图 1.1" or "Figure 1.1" (Chinese/English hybrid) |
| Table label | "表 1.1" or "Table 1.1" |
| Caption | Centred, below figure / above table |

## Formatting

- A4 paper, single column
- Font: Song Ti (宋体) for Chinese, Times New Roman for English
- Line spacing: 1.5 or double
- Page numbers centred at bottom
- Binding margin on left (for print submission)
