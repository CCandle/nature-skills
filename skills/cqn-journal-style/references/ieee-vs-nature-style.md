# IEEE vs Nature Style Comparison

## Section structure

| Element | IEEE | Nature |
|---|---|---|
| Section numbering | Roman (I, II, III) | Unnumbered |
| Abstract | Single paragraph | Single paragraph, 150 words |
| Introduction | Section I | Introduction (unnumbered) |
| Methods | Last numbered section | After Discussion (online) |
| References | [1], [2] | 1, 2, 3 |

## Figure and table formatting

| Element | IEEE | Nature |
|---|---|---|
| Figure label | "Fig. 1." | "Figure 1." |
| Table label | "TABLE I" (caps) | "Table 1" |
| Caption position | Below figure | Below figure |

## Citation style

| Element | IEEE | Nature |
|---|---|---|
| In-text | [1], [2, Fig. 3] | 1, 2 |
| Reference order | Order of appearance | Order of appearance |
| Author list | All authors | Up to 5, then et al. |
