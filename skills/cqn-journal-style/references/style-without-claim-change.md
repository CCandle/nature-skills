# Style-Without-Claim-Change Rules

Journal style alignment must not alter the technical claims or evidence
of the manuscript.

## What style alignment MAY change

| Item | Example |
|---|---|
| Section ordering | Introduction before Related Work |
| Heading style | Roman numerals (IEEE) vs unnumbered (Nature) |
| Citation format | [1] vs (Author, Year) |
| Figure label | "Fig. 1" vs "Figure 1" |
| Table label | "TABLE I" vs "Table 1" |
| Abstract format | Structured vs unstructured |
| Paragraph density | Shorter paragraphs for Nature |
| Reference formatting | Journal name abbreviations |

## What style alignment MUST NOT change

| Item | Reason |
|---|---|
| Technical meaning | Evidence integrity |
| Claim strength | "is" vs "may be" distinction |
| Numerical values | Data integrity |
| Units | Measurement reproducibility |
| Limitations | Intellectual honesty |
| Evidence tags [CF]/[RH]/[UG] | CQN evidence discipline |

## Conflict resolution

If a journal style guide conflicts with evidence discipline (e.g.,
the journal requires omission of limitations to fit a page limit),
evidence discipline wins. Flag the conflict to the author.
