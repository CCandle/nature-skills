# IEEE Style

## Sections
Numbered with Roman numerals: I, II, III, IV, V.
Subsections: A, B, C. Sub-subsections: 1, 2, 3.

## Citations
Numbered in brackets: [1], [2, Fig. 3], [3]-[5].
Reference list at end, numbered by order of first appearance.

## Figures
Label: "Fig. 1." Caption below.
Tables: "TABLE I" (all caps). Caption above.

## Abstract
Single paragraph, 150-250 words. No citations.

## Format
Two-column layout for final submission. Single-column for initial submission.
