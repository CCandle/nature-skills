# Generic Engineering Journal Style

## Sections
Numbered: 1, 2, 3. Subsections: 1.1, 1.2.
Flexible; follow the specific journal's author guide.

## Citations
Author-year or numbered per journal.
Reference list at end.

## Figures
Label: "Fig. 1" or "Figure 1" per journal.
Tables: "Table 1".

## Abstract
Structured (Background, Methods, Results, Conclusions) or unstructured
per journal preference.
