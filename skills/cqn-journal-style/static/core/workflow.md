# Style Alignment Workflow

## Step 1: Identify target style
Confirm the specific journal or format with the user.

## Step 2: Load style fragment
Apply the style-specific conventions.

## Step 3: Apply changes
- Adjust heading hierarchy
- Reformat citations
- Adjust figure and table labelling
- Reorganise sections if required by the journal
- Adjust abstract format

## Step 4: Generate change summary
List every modification with location and reason.
