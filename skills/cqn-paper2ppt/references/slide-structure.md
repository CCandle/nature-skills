# Slide Structure Guidelines

## One slide, one question

Each slide should answer exactly one question that the audience might
have at that point in the talk. Example sequence:

- "What is the problem?" → Slide 2
- "How does existing work address it?" → Slide 3
- "What is your approach?" → Slide 4
- "Does it work?" → Slides 5-7

## Content density

- 3-5 bullet points maximum per slide
- One figure per results slide; multiple small panels on one slide only
  if they answer the same question
- Font size: 24 pt minimum for body text, 18 pt for references

## Slide titles

- Titles should be informative, not descriptive
  - Good: "ADC ENOB improves from 9.2 to 10.8 bit with external Vref"
  - Bad: "Results"
