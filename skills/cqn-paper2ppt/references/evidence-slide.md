# Evidence Slide

## When needed

Include an evidence slide when a single result slide does not capture
the full set of supporting evidence, or when multiple claims need to
be traced to their sources.

## Table format

| Claim | Evidence | Tag |
|---|---|---|
| ADC offset = 5 LSB | lab-record-20260609 | [CF] |
| Vref noise dominates | ADR4520 datasheet | [RH] |

## Rules

- One claim per row
- Evidence column references the specific source
- Tag column uses [CF]/[RH]/[UG]
