# Experiment Platform Slide

## When needed

Include an experiment platform slide when:
- The hardware configuration changed since the last presentation
- The audience is not familiar with the setup
- The results depend on specific instrument settings

## What to include

- Board model and revision
- Firmware / bitstream commit hash
- Instrument model and settings
- Diagram or photo of the setup (optional but recommended)
- Key parameters: sampling rate, bandwidth, probe type
