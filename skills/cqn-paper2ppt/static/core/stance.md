# Stance

## Oral communication first

Slides support the talk, not replace it. Each slide should be readable
in 5 seconds. The speaker provides the detail.

## Evidence traceability

Every result slide must reference where the data came from. A slide
showing a waveform without source attribution is not useful.

## Complete but not verbose

Include enough information for a viewer who missed the talk to
understand the key points. Do not include the full lab record.
