# Experiment Progress Deck

Weekly or biweekly lab progress update.

## Slide sequence

| # | Slide title | Content |
|---|---|---|
| 1 | Title | Project name, date, objective |
| 2 | Objective | What was the goal of this experiment session? |
| 3 | Platform | Current hardware/software configuration |
| 4 | Setup | Experiment setup with key parameters |
| 5 | Key Results | Best waveform, metric, or comparison |
| 6 | Evidence Table | Claims with [CF]/[RH]/[UG] tags |
| 7 | Failure Cases | What didn't work and why |
| 8 | Diagnosis | Root cause analysis summary |
| 9 | Next Steps | Prioritised experiments for next session |
| 10 | Help Needed | Decisions or resources needed |

## Notes

- If no experiment data exists yet, the "Key Results" slide should
  say "Not yet measured" — not be omitted.
- The "Help Needed" slide should contain specific questions, not
  general requests.
