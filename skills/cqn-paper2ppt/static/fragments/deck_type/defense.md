# Defense Deck

Thesis or project defense presentation.

## Slide sequence

| # | Slide title | Content |
|---|---|---|
| 1 | Title | Thesis title, candidate, supervisor |
| 2 | Background | Problem space, motivation |
| 3 | Problem Definition | Specific problem addressed |
| 4 | Related Work | Key prior work, gap |
| 5 | Method | Proposed approach and architecture |
| 6 | System Design | Key design decisions, trade-offs |
| 7 | Experimental Setup | Platform, parameters, conditions |
| 8 | Results | Key experimental results with evidence |
| 9 | Innovation / Contribution | What is new, with evidence basis |
| 10 | Limitations | Honest assessment of boundaries |
| 11 | Future Work | What is next |
| 12 | Q&A | Thank you and guidance for questions |

## Notes

- Slide 3 (Problem Definition) should be understandable by a
  non-specialist committee member.
- Slide 10 (Limitations) is mandatory — a defense without limitations
  looks like overclaiming.
- Each result on slide 8 should reference its evidence source in the
  speaker notes.
