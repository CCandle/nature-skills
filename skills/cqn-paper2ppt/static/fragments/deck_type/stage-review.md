# Stage Review Deck

End-of-phase or milestone review presentation.

## Slide sequence

| # | Slide title | Content |
|---|---|---|
| 1 | Title | Phase name, period, project |
| 2 | Goal of This Phase | What was planned |
| 3 | Work Completed | Summary of experiments and analysis |
| 4 | System Architecture | Final hardware/software configuration |
| 5 | Experimental Validation | Key results with evidence |
| 6 | Results Summary | Metrics table vs targets |
| 7 | Risks | Risk register update |
| 8 | Lessons Learned | What would be done differently |
| 9 | Next Phase Plan | Objectives, timeline, resources |
| 10 | Open Questions | For the review committee |

## Notes

- Include a one-slide summary of hardware version, firmware commit,
  and software configuration for traceability.
- If a phase objective was not met, explain why on the slide, not
  in supplementary material.
